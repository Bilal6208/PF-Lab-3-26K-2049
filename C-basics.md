Multiple Data Types:

1. Integer---int-----25
2. Boolean---bool-----0 and 1
3. Character---char-----a
4. Float---float-----45.6
5. Void---void-----void print ("Hello")
6. Double---double-----9.87321

Format Specifiers:

1. %d: int
2. %u: unsigned int
3. %o:	unsigned int
4. %x:	unsigned int
5. %X:	unsigned int
6. %f:	float (and double in printf)
7. %e:	float (and double in printf)
8. %c:	char
9. %s:	char * (String / Character array)
10. %ld: long int

Inbuilt Functions:

1. scanf(): Reads formatted data from the keyboard and stores it into specified variables.
2. printf(): Displays formatted text and variables to the screen.
3. getchar(): Reads and returns a single character from the standard input.
4. putchar(): Writes a single character directly to the standard output.
5. fgets(): Safely reads a complete line of text, including spaces, up to a specific length to prevent buffer overflows.
6.puts(): Prints a string to the screen and automatically adds a newline at the end.

Precision
Precision for floating-point output is specified by placing a period (.) followed by a number between the % and the f in the format specifier (e.g., %.2f). This number dictates exactly how many digits to display after the decimal point, and the system will automatically round the final digit.

Escape Characters:

1. \n (Newline): Moves the cursor to the beginning of the next line.
2. \t (Horizontal Tab): Inserts a block of blank space to align text.
3. \\ (Backslash): Prints a single, literal backslash character.
4. \" (Double Quote): Prints a literal double quotation mark inside a string.
5. \' (Single Quote): Prints a literal single quotation mark.
